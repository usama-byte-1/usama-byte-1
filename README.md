## 🤖 AI, LLMs & RAG

AI is an area I'm actively exploring and building in. I'm interested in making language models useful inside real applications, where they need to work with existing data, follow business rules, and return useful results.

Some of the areas I work on or follow closely include:

- Integrating LLMs into backend applications and existing workflows.
- Building Retrieval-Augmented Generation (RAG) systems that retrieve relevant information before generating an answer.
- Working with embeddings, document chunking, retrieval, vector search, and context construction.
- Exploring hosted models and open-weight model families, including OpenAI GPT, Anthropic Claude, Google Gemini, Meta Llama, Qwen, DeepSeek, and Mistral.
- Exploring local model deployment and inference tools such as Ollama and vLLM.
- Following AI application frameworks and agent workflows, including LangChain, LangGraph, and LlamaIndex.
- Using AI coding tools such as Claude Code and OpenAI Codex to help investigate codebases, understand unfamiliar code, and speed up development while still reviewing and testing the results.

The AI ecosystem changes quickly, so I try to understand the differences between models and tools instead of relying on one provider or following every new release. For me, the important part is choosing the right approach based on accuracy, performance, cost, privacy, and the needs of the application.
